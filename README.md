# HeartPlugin

一个让“心”可以赠予、掉落与合成的 Minecraft 服务器插件。

## 玩法介绍

- 赠送之心：执行 `/heart`，扣掉自己的一颗心，获得一个闪闪发光的“心”。
- 吃下苹果：把苹果交给朋友或留给自己，吃下后永久提升最大生命值（一颗心 = 2 点生命）。
- 死亡掉落：每次死亡都会掉落一颗“心”，同时永久失去一颗心,复活后需要找回掉落的心。

## 命令

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/heart` | 扣一颗心，获得一个“心”苹果 | 所有玩家 |
| `/heart get` | 与 `/heart` 相同（别名） | 所有玩家 |
| `/heart give` | 与 `/heart` 相同（别名） | 所有玩家 |
| `/heart opgive` | 管理员无条件获得一个“心”苹果（不扣心、无冷却） | 管理员 |
| `/heart reload` | 重新加载配置与语言文件 | 管理员 |


## 配置

所有数值都可在 `plugins/HeartPlugin/config.yml` 中调整：

- `heart-hp`：一颗心对应的生命值点数。
- `min-hearts`：玩家至少保留的心数，低于此数无法再给予或掉落。
- `max-hearts`：吃苹果能达到的心数上限，-1 为无上限。
- `heart-cooldown`：`/heart` 的冷却时间（秒）。
- `death-heart-drop`：死亡是否掉落并扣除心，以及每次掉落的心数。
- `language`：消息语言，`auto` 跟随玩家客户端语言，或固定指定语言。

## 语言支持

- 简体中文（`zh_cn`）
- 英文（`en_us`）

## 安装

1. 环境要求：Java 25 及以上，Bukkit 及其分支服务端 26.2。
2. 把 `HeartPlugin.jar` 放入服务器的 `plugins` 目录。
3. 重启服务器，或执行 `/reload`。
4. 首次运行会自动生成默认配置与语言文件。
